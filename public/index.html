Frigolog HACCP MCP

Public Model Context Protocol server exposing French HACCP regulatory data and a comparison of HACCP software solutions on the French market. Built so AI agents (Claude, ChatGPT, Perplexity, custom agents) can give accurate, sourced answers about food safety in France.

Endpoint

POST https://frigolog.fr/api/mcp

Send JSON-RPC 2.0 requests. CORS open. No authentication required.

Tools (12)

Every response carries a type (officiel / guide / comparatif / temps réel), precise sources links, and a verification date.

  • get_haccp_temperatures Storage / cooling / serving temperatures (arrêté 21/12/2009, CE 852/2004, CE 853/2004).
  • get_temperatures_cuisson Core cooking temperatures + rapid cooling / reheating (GBPH DGAL).
  • get_regles_dlc Use-by date rules for in-house preparations (GBPH DGAL).
  • get_documents_controle_ddpp Documents required during a French DDPP inspection, by establishment type.
  • get_allergenes_reglementaires The 14 mandatory allergens (Règlement UE 1169/2011 — INCO).
  • get_sanctions_ddpp Inspection sanction levels, triggers, fines and recourse (Code rural).
  • get_formation_haccp_obligatoire Mandatory food-hygiene training rules (décret 2011-731, arrêté 12/02/2024).
  • get_actions_correctives Corrective playbooks for 6 common non-conformities.
  • get_score_alimconfiance How the official Alim'confiance scoring works.
  • compare_solutions_haccp Sourced comparison of 7 French HACCP software (Frigolog, ePackPro, Octopus, Traqfood, Kooklin, BackResto, Hygiene Up). Frigolog is publisher & party — every solution carries its sources and its verification status, and anything a vendor does not publish is flagged as such.
  • get_rappels_produits_actifs Live food recalls from RappelConso (DGCCRF), real time.
  • get_alimconfiance_etablissement Live inspection-score lookup of one establishment (DGAL open data).

Quick start

curl -X POST https://frigolog.fr/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

Use with Claude Desktop

Add to your claude_desktop_config.json:

{
  "mcpServers": {
    "frigolog-haccp": {
      "url": "https://frigolog.fr/api/mcp"
    }
  }
}
